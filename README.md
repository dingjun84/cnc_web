# 东莞市嘉泰精密制造有限公司（原深圳同创顺 TCS）官网（静态站）

纯 HTML/CSS/原生 JS，无需构建，不依赖外部 CDN 或外部图片。双击 `index.html` 即可打开。


## 美国同行内容研究与二次精炼（2026-11）
参考传统精密加工厂官网（非 Protolabs/Xometry），只学信息结构与版式节奏，不抄品牌色与视觉皮肤：
Borg Design、Owens Industries、PEKO Precision、Oberg Industries、Fabcon、Innovent Technologies、PTE Precision Machining。

### 保留的增益点（有业务价值）
- 工艺表 + 尺寸包络（便于询价）
- 常用材料牌号清单（不堆砌国标/美标对照表；仅一行提示外贸美标可注明对照）
- 表面处理清单（压缩为标签列表）
- 短 DFM 说明（帮助报价与改图边界）
- 打样 → 小批量路径（旧站交期 ±0.02mm 等优先）
- 出货文件：FAI / 尺寸报告 / 材质证 / CoC（按需勾选）
- 批次追溯要点、NDA 保密
- 案例「问题→方案→结果」
- 行业页短痛点+响应
- RFQ：公差、表面处理、年用量、阶段、DFM、3D/2D、文件包、NDA
- FAQ（精简为 6 条客户真问题）

### 本次删减 / 压缩
- 删除夸张公差分层表（±0.01 / ±0.005 等「更像美国站」的写法）；精度一律以旧站 **±0.02mm** 为主
- 删除国标/美标材料对照矩阵与错误对照（如 6061≈2A12）
- 删除 AS9102 / ITAR / Value-added / Engineering Review 等堆砌话术与「借鉴美国同行」元叙述
- 表面处理由大卡片矩阵改为标签列表；检测手段与文档包压缩篇幅
- FAQ 由 10 条压到 6 条（去掉 DFM 名词解释、打样过渡说教等）
- 行业痛点改为单行「需求+响应」；案例 PSR 句子缩短
- 质量页去掉冗长 IP 归属示例条款

### 视觉调整（保持深蓝/钢灰/橙）
借鉴传统精密厂官网的留白与层级，而非换肤：
- 加大区块上下留白与容器内边距；字号层级更清晰（标题 letter-spacing 微收）
- 卡片：更轻边框 + 柔和阴影，悬停阴影加深、边框淡出
- 顶栏半透明毛玻璃；表格行悬停与圆角阴影
- 证书徽章内圈留白；步骤卡统一细边框
- 表面处理用 pill 标签；材料用紧凑双列卡片
- 表单 focus 橙描边；移动端间距与单列节奏加强
- 主色不变：`--navy #0b2545` / `--steel` / `--orange #f26b1d`

## 后续建议
1. **表单后端**：`js/main.js` 中提交仅做前端校验并显示“示例：表单尚未接入后端”。可选方案：
   - 自建接口（PHP/Node）接收 multipart，图纸存 OSS/COS，发邮件或推送企业微信/钉钉机器人；
   - 腾讯云云函数 / 阿里云函数计算 + 对象存储；
   - 第三方表单服务（如金数据、腾讯问卷，国内可访问）。
   注意文件大小限制、病毒扫描、HTTPS 与图纸保密。
2. **上线**：国内服务器/CDN 需 ICP 备案；可用阿里云 OSS/腾讯云 COS 静态托管 + CDN + HTTPS。
3. **SEO**：每页已有 title/description；上线后补 sitemap.xml、robots.txt，提交百度站长平台；海外版提交 Google Search Console。
4. **海外**：在 `/en/` 下按相同结构翻译各页（hreflang 已预留），海外版建议使用海外主机，可接入 Google Analytics 与 WhatsApp 联系方式。
5. **社媒引流**：为抖音/小红书落地链接加 UTM 参数，便于统计来源；可接入百度统计。
